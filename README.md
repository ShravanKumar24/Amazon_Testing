# 🛒 E-Commerce Web Application Testing

A comprehensive QA project covering Manual Testing, Selenium Automation, and API Testing for an E-Commerce web application (Amazon-like platform).

---

## 📌 Project Overview

This project demonstrates end-to-end software testing of an E-Commerce application covering critical user flows including login, product search, cart management, checkout, and order management.

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| Java | Programming Language |
| Selenium WebDriver | Browser Automation |
| TestNG | Test Framework |
| Maven | Build Tool |
| Apache POI | Data-Driven Testing |
| Extent Reports | Test Reporting |
| Git & GitHub | Version Control |

---

## 📂 Project Structure

```
Amazon_Testing/
├── src/
│   ├── main/java/
│   │   ├── base/          → BaseClass, Browser setup
│   │   ├── pages/         → Page Object Model classes
│   │   └── utils/         → Utility methods
│   └── test/java/
│       └── tests/         → Test classes
├── data/                  → Excel test data (Apache POI)
├── reports/               → Extent Report HTML output
├── testxmlfiles/          → TestNG XML suite files
└── pom.xml                → Maven dependencies
```

## ▶️ How To Run

```bash
# Clone the repository
git clone https://github.com/ShravanKumar24/Amazon_Testing.git

# Navigate to project
cd Amazon_Testing

# Run tests using Maven
mvn test

# Or run specific TestNG suite
# Right-click testng.xml → Run As → TestNG Suite
```
